

jogos_android_14bis
===================

Juego 14 bis para Android creado en el libro Desarrollo de Juegos para Android con Cocos2D:

http://www.casadocodigo.com.br/products/livro-jogos-android

Puede descargar el proyecto completo, pero recomendamos encarecidamente intentar seguir los pasos y explicaciones del libro. 

Las imágenes, sonidos y otros archivos también pueden descargarse aquí. Para ello, obtenga los archivos en el directorio assets.
